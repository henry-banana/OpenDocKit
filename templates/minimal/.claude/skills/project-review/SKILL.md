# Project Review

Read the requested revision/diff and the relevant requirement/domain/contract authority. Check correctness, compatibility and concrete failure cases. Distinguish verified findings from hypotheses.

Return findings with file/location, trigger, consequence and evidence. State checks run/failed/not run and remaining risks. Do not mutate code, publish, spawn agents or invent approval merely because the skill was loaded.
