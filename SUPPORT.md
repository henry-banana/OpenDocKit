# Support

## Start here

Use the [README](README.md) to get started and the [template index](INDEX.md) to
find a concern, project type or workflow. For changes to the library, see
[CONTRIBUTING.md](CONTRIBUTING.md).

Search [existing issues](https://github.com/henry-banana/OpenDocKit/issues) before
opening a new one. Include the source path and commit/version when asking about
a particular template.

## Choose a route

| Need | Where to go |
| --- | --- |
| A broken link, misleading prompt, invalid sample or failing maintainer check | [Bug report](https://github.com/henry-banana/OpenDocKit/issues/new?template=bug_report.yml) |
| Documentation for a reader task the library does not cover | [Template request](https://github.com/henry-banana/OpenDocKit/issues/new?template=template_request.yml) |
| Help choosing/adapting templates, or a navigation/tooling suggestion | [Improvement or question](https://github.com/henry-banana/OpenDocKit/issues/new?template=improvement.yml) |
| A sensitive security concern | [Security reporting](SECURITY.md) |
| A conduct concern | [Code of Conduct reporting](CODE_OF_CONDUCT.md#reporting-a-concern) |

If a hosted form is unavailable, use the
[issue chooser or a blank issue](https://github.com/henry-banana/OpenDocKit/issues/new/choose).

## Make the question actionable

Describe what you were trying to document, the selected representation, affected
source/destination paths and the outcome you expected. For a defect, include a
minimal reproduction and relevant diagnostics. For tool/client problems, include
OS and version information and distinguish syntax checks from actual loading.

Use a small sanitized example. Keep credentials, private project records,
personal information and raw private session transcripts out of public issues.

## What support covers

Community support covers using OpenDocKit, improving its templates and maintaining
its checks. A template is a starting point; your team owns its project-specific
facts, review decisions and ongoing maintenance. Issues in an adopted application
or an agent client may need the responsible project's support channel.

Help is provided as maintainers and contributors are available. There is no
guaranteed response time or commercial support agreement. Follow the
[Code of Conduct](CODE_OF_CONDUCT.md) in support discussions.
