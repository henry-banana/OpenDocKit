## Responsibility preservation

The [migration map](migration-map.json) is a historical snapshot, not the current inventory. Use [INDEX](../INDEX.md) and the actual source tree for current paths.

Regulated certification, specialized legal/industry controls and target-project executable CI/MCP/hook setups require their own source/domain review. Common security/privacy/ownership obligations remain available rather than being silently removed.
